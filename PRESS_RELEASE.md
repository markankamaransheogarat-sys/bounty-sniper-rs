## Заголовок
**bounty-sniper-rs v0.1.0 — высокочастотный сканер GitHub-баунти на Rust с фильтрацией спама и Telegram-алертами**

## Ключевые возможности
- **Быстрый сканер GitHub Issues/PR** с локальным кэшированием (`sniper_cache.json`).
- **Умная фильтрация**: отсеивание спам-репозиториев/авторов, хакатонов, расплывчатых незафондированных задач и уже занятых/конкурирующих PR (`CONTESTED`, `HOLD`).
- **11/11 unit-тестов (`cargo test`) проходят**, релизный профиль с `LTO` и `strip`.
